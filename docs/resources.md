# Resources

- `exact://products`: requested product, configuration state, and catalog source.
- `exact://capabilities`: detected and verified capability summary.
- `exact://policies`: effective non-secret access policy.
- `exact://synergy/entities`: allowed Synergy entity summaries.
- `exact://globe/entities`: allowed Globe+ entity summaries.
- `exact://synergy/entities/{name}`: full allowed entity schema.
- `exact://globe/entities/{name}`: full allowed entity schema.

The entity templates support listing and name completion. Resources contain no passwords, access tokens, private connection URLs, or record data. Their catalog is generated from the configured installation's metadata or an explicitly configured local metadata cache.
